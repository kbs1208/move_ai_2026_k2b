# Air Nego — Air Cargo Negotiation Agent (해커톤 프로토타입)

항공 화물 운송편을 **스케줄·데드라인 제약** 하에 탐색하고, 항공사들과 **견적(RFQ) → 카운터오퍼 네고**를
메일로 진행(시뮬레이션)하여 **최적 예약 조건을 근거와 함께 추천**하는 AI 에이전트.

- 에이전트 입력: 주문(구간, CW=max(GW,VW), 준비일, 희망도착일, 데드라인)
- 에이전트 출력: "어떤 편에, 어떤 날짜에, 얼마로 예약하세요" + 근거(마크다운)
- 메일은 실제 발송 없음 — 화면에 표현만 (전부 한국어/KST, 통일된 서명 형식)

---

## 데모 시나리오

1. **주문 · AI 에이전트** 탭에서 주문 선택 → 상세 확인 → `AI 에이전트 실행`
   - 후보편 탐색 → 과거 합의수준 분석 → RFQ 메일 발송 → 회신 해석(시장 range) → 카운터오퍼 네고 → 추천
   - 전 과정 실시간 타임라인 + 항공사별 견적 현황 + 상태 배지(회신 n/m) 표시 (~1분 소요)
   - 실행은 서버에서 구동되고 전역 SSE로 브로드캐스트 — **여러 사용자가 동시에 같은 진행 상황을 실시간 확인**
2. 추천 카드에서 근거·네고 메일 내역(항공사별) 확인 후 `이 조건으로 예약 확정`
   - 확정 시 **AWB 자동 채번**(항공사 prefix 3자리 + 8자리) 후 항공사에 회신 메일 발송
   - 확정된 주문은 **BOOKED(종착 상태)** — 재실행/변경 불가
3. **가격 테이블 / 스케줄 테이블** 탭 — 요율·항공사별 할증·운항 스케줄 원본 조회
4. **항공사 담당자** 탭 — 컨택 포인트 및 AWB prefix
5. **운영 대시보드** 탭 — 총 금액/절감액/할인율/성사 건수, 항공사·구간별 집계 (실시간 반영)

---

- 실행 결과(네고 메일, 추천, 예약)는 SQLite에 저장되어 **서버 재시작에도 유지**

## AI 기능 매핑

- 메일 발송 Form 생성 → `agent.gen_rfq_emails`, `gen_counter_emails`
- 수신 메일 body 해석 → `agent.parse_quote_emails` (시뮬레이터 제시가와 1% 초과 불일치 시 방어)
- 최적 예약정보 추천 + 근거 → `agent.run_agent` 스코어링 + `gen_rationale`
